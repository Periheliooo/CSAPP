CSAPP — Computer Systems: A Programmer's Perspective

My lab work and exercises while self-studying *Computer Systems: A Programmer's Perspective*, covering data representation, machine-level programming, process control, and memory allocation.

| [lab3attacklab](lab3attacklab/) | Stack behavior, buffer overflows, and code-reuse attacks. |
| [lab6shlab](lab6shlab/) | Shell implementation, signals, and job control. |

The repository contains course-provided lab materials and my work on the exercises. Some labs retain multiple working copies; build and test instructions are provided within the individual lab directories.
